## О проекте

Автоматизированная система для учёта, контроля и анализа обращений граждан.  
Заменяет бумажные журналы и Excel-файлы. Реализованы:

- База данных в MS SQL Server (нормализация 3НФ)
- Клиентское приложение WPF (.NET Framework 4.8, C#)
- CRUD, фильтрация, поиск, пагинация, экспорт в CSV
- Ролевая модель (руководитель, оператор, исполнитель)
- Регистрация граждан с хешированием паролей (BCrypt)
- Резервное копирование (6 копий) и восстановление
